# IDon

An independently implemented DaBoys apps hub. The interface and behavior are being recreated with new React, TypeScript, and CSS code rather than importing Macaly source files.

## Features

- App launcher for DaEconomy, DaCourt, DaMusic, Settings, and DeviceTest
- Search and desktop drag-to-reorder in edit mode
- App folders
- Built-in and custom wallpapers saved locally in the browser
- DaMusic demo player and volume control
- Control Center and device check
- Responsive layout and installable web app metadata

## Run locally

Install Node.js, then run:

```sh
npm install
npm run dev
```

To make a production build:

```sh
npm run build
```

This repository is separate from `IDA-OS`.
